## 关于 05 / 06 / 07 三节的重写

原课程这三节是 Axure 教程：

- 05 原型及 Axure 介绍
- 06 Axure 交互进阶（Toast、呼出键盘、省市二级联动、步进器、全局变量）
- 07 中继器与交互自查

其中操作部分已经过时——中继器解决的是「在原型工具里模拟一个能增删改查分页的数据表格」，这件事现在该交给真代码。

重写后：

- **05 原型基础** —— 保留三节里跟工具无关的方法论（原型分类、设计规范、交互思想、交互自查），并更新了其中过时的数据（移动端尺寸从 375×667 更新到 393×852，同时更正了原笔记「iPhone 5/6/7/8 分辨率都是 750×1334」这处错误）
- **06 Figma 实战** —— 原创。含 Axure → Figma 的迁移对照表
- **07 让 AI 直接做 HTML 原型** —— 原创。含完整 Prompt 和一个可运行原型
